# IP网络故障诊断 — 通用规范

本文件是所有场景技能（`SKILL-*.md`）的公共依赖，包含采集规范、执行约束、诊断流程、
自检清单、追问流程，以及各场景共享的基础设施故障章节（§3.x）。

## 1. 采集规范

- 所有命令回显必须完整粘贴，不得截断、不得改写。
- 每条结论必须给出支撑回显的来源（设备名 + 命令 + 时间）。

## 2. 执行约束

- 只执行只读诊断命令；配置变更需人工确认后执行。
- 未采集到证据时不得给出根因结论，应输出「证据不足 + 待采集清单」。

## 3. 共享基础设施故障

### 3.0 强制前置采集

无论什么故障类型，进入决策树前必须先采集配置变更记录与拓扑变化日志。

```
display configuration commit list
display alarm active
```

### 3.1 物理端口故障

接口物理层 DOWN、光口无光、端口被 shutdown。

```
display interface brief
display interface GigabitEthernet0/1/0
```

### 3.2 设备离线故障

设备失联、管理面不可达、设备重启。

### 3.4 光模块故障

光模块不在位、型号不匹配、模块告警。

### 3.5 光功率故障

收发光功率超出门限。

### 3.6 链路故障

链路误码、单通、中间传输设备异常。

### 3.8 OSPF状态异常

OSPF 邻居非 Full、区域配置不一致、路由不可达。

### 3.11 BFD会话异常

BFD 会话 Down 导致上层协议联动切换。

### 3.16 单板故障

单板离线、复位、状态异常。

### 3.17 子卡故障

子卡不在位或状态异常。

### 3.18 光功率过低

接收光功率低于下门限。

### 3.19 光功率过高

接收光功率高于上门限。

### 3.20 L3VPN业务故障

VPN 实例路由缺失、RT 配置不匹配。

### 3.21 风扇故障

风扇转速异常或告警。

### 3.23 Tunnel故障

Tunnel 接口 DOWN 或不可用。

### 3.25 LDP故障

LDP 会话无法建立或异常中断。

### 3.26 MPLS故障

MPLS 转发异常、标签分配失败。

### 3.27 SRv6 TE Policy故障

SRv6 TE Policy 不生效、SID 不可达。

### 3.30 EVPN故障

EVPN 路由不通、隧道未建立。

### 3.31 自检清单

- [ ] §3.0 强制前置采集已执行
- [ ] 每条根因都有回显证据
- [ ] 结论中给出了下钻到底层的判断依据

## 4. 诊断后追问流程

输出结论后，向用户确认：故障是否恢复、是否需要变更配置、是否需要保留现场。
